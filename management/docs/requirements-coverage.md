| 后台业务管理 | - | 七个业务模块均支持列表、新增、编辑和删除 | 工作区隔离 CRUD、审计与软删除 | 完成 |

## 明确不改的范围

- USB / YUV / MJPG / 帧率 / 板卡 / 硬件存储与硬件清理逻辑。
- 没有硬件或外部系统接口的功能，只实现页面、状态模型和 API 契约。
- 分辨率自动切换暂不在本轮处理，现有 device/mobile 构建与分端逻辑保留。
