# 08 — 持久化方案：开机自启 Kiosk 全链路

> 日期：2026-07-23
> 硬件：LubanCat-4 V1 (RK3588) + 野火 5.5 寸 MIPI DSI

---

## 问题

以下配置在重启后全部丢失：

| 配置 | 重启后 | 原因 |
|------|--------|------|
| `xrandr --rotate right` | ❌ 丢失 | X 会话级，非持久 |
| `xinput set-prop 触摸矩阵` | ❌ 丢失 | X 会话级，非持久 |
| Node.js server.js | ❌ 未启动 | 手动后台运行 |
| Chromium Kiosk | ❌ 未启动 | 手动后台运行 |
| Xorg :0 | ❌ 未启动 | GDM 已禁用 |

---

## 方案：3 个 systemd 服务

```
开机
 │
 ├─ xserver.service       Xorg :0 -nocursor -ac vt1
 │
 ├─ device-ui.service     Node.js :8080
 │      │
 │      └─ kiosk.service  ─→ xrandr --rotate right
 │                           ─→ xinput 触摸矩阵
 │                           ─→ Chromium Kiosk
```

### 服务 1：xserver.service

```ini
# /etc/systemd/system/xserver.service
[Unit]
Description=Xorg X Server
After=systemd-user-sessions.service

[Service]
Type=simple
User=root
ExecStart=/usr/bin/Xorg :0 -nocursor -ac vt1
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

要点：
- `-nocursor`：嵌入式 Kiosk 不需要鼠标光标
- `-ac`：禁用 X 访问控制（SSH 远程启动 Chromium 时不报 Xauth 错）
- vt1：绑定到虚拟终端 1

### 服务 2：device-ui.service

```ini
# /etc/systemd/system/device-ui.service
[Unit]
Description=Device UI Server
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/ui
ExecStart=/usr/bin/node /root/ui/server.js
Restart=always
RestartSec=3
Environment=PORT=8080

[Install]
WantedBy=multi-user.target
```

要点：
- 零 npm 依赖，Node.js 原生模块启动
- `Restart=always`：进程崩溃自动重启

### 服务 3：kiosk.service

```ini
# /etc/systemd/system/kiosk.service
[Unit]
Description=Chromium Kiosk
After=xserver.service
Requires=xserver.service

[Service]
Type=forking
User=root
Environment=DISPLAY=:0
ExecStartPre=-/usr/bin/pkill chromium
ExecStartPre=/bin/sleep 2
ExecStartPre=/usr/bin/xrandr --output DSI-1 --rotate right
ExecStartPre=/usr/bin/xinput set-prop 8 'Coordinate Transformation Matrix' 0 1 0 -1 0 1 0 0 1
ExecStart=/bin/sh -c '/usr/bin/chromium --kiosk --no-first-run --noerrdialogs --disable-session-crashed-bubble --window-size=1920,1080 http://localhost:8080 &>/tmp/chromium.log &'
ExecStop=/usr/bin/pkill chromium
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

要点：
- `Type=forking`：Chromium 后台运行，systemd 不阻塞
- `Requires=xserver.service`：Xorg 挂了会自动重启 Kiosk
- `ExecStartPre` 链：先杀掉旧 Chromium → 等 2 秒 → 旋转屏幕 → 触摸校准 → 启动
- `pkill` 前面的 `-`：第一次启动没旧进程也不报错

## 部署命令

```bash
# 创建服务文件
cat > /etc/systemd/system/xserver.service << 'UNIT'
[Unit]
Description=Xorg X Server
After=systemd-user-sessions.service

[Service]
Type=simple
User=root
ExecStart=/usr/bin/Xorg :0 -nocursor -ac vt1
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
UNIT

cat > /etc/systemd/system/device-ui.service << 'UNIT'
[Unit]
Description=Device UI Server
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/ui
ExecStart=/usr/bin/node /root/ui/server.js
Restart=always
RestartSec=3
Environment=PORT=8080

[Install]
WantedBy=multi-user.target
UNIT

cat > /etc/systemd/system/kiosk.service << 'UNIT'
[Unit]
Description=Chromium Kiosk
After=xserver.service
Requires=xserver.service

[Service]
Type=forking
User=root
Environment=DISPLAY=:0
ExecStartPre=-/usr/bin/pkill chromium
ExecStartPre=/bin/sleep 2
ExecStartPre=/usr/bin/xrandr --output DSI-1 --rotate right
ExecStartPre=/usr/bin/xinput set-prop 8 'Coordinate Transformation Matrix' 0 1 0 -1 0 1 0 0 1
ExecStart=/bin/sh -c '/usr/bin/chromium --kiosk --no-first-run --noerrdialogs --disable-session-crashed-bubble --window-size=1920,1080 http://localhost:8080 &>/tmp/chromium.log &'
ExecStop=/usr/bin/pkill chromium
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
UNIT

# 启用
systemctl daemon-reload
systemctl enable xserver.service device-ui.service kiosk.service
systemctl start xserver.service device-ui.service kiosk.service
```

## 验证

```bash
# 检查三个服务
systemctl status xserver.service --no-pager | head -4
systemctl status device-ui.service --no-pager | head -4
systemctl status kiosk.service --no-pager | head -4

# 检查进程
pgrep -a Xorg
pgrep -a node
pgrep -a chromium | head -1

# 检查触摸矩阵
DISPLAY=:0 xinput list-props 8 | grep 'Transformation Matrix'
# 预期: 0 1 0 -1 0 1 0 0 1
```
