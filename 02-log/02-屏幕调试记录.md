### 17:32 — 启动 Chromium Kiosk（第一次失败）

Chromium 报错 `Unable to open X display`。原因是 SSH 会话缺少 X authority cookie，且 `/root/.Xauthority` 不存在。

**根因：** 从无桌面环境的 SSH 启动 Xorg 后，后续 SSH 会话没有 Xauth cookie。

---

### 17:35 — 重启 Xorg + `-ac` 参数

```bash
pkill Xorg
Xorg :0 -nocursor -ac vt1 &
```

`-ac` 禁用 X access control，允许任何连接。

---

## 踩坑记录

1. **DSI overlay 被注释** — uEnv.txt 中需要手动取消注释，EEPROM 自动识别不一定生效
2. **eprobe_defer** — dmesg 中 `Failed to find panel or bridge: -517` 是正常的 deferred probe，驱动加载顺序问题，会自动重试
3. **X authority** — 无桌面环境的 SSH 启动 Xorg 需要用 `-ac` 参数，否则后续进程无法连接 display
4. **apt 无 DNS** — 板子通过 USB 以太网直连 Mac，无外网共享时无法解析域名。需要在 Mac 上开启 Internet Sharing 或手动下载 .deb 包
