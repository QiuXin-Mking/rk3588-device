## 物理检查步骤

### ⚠️ 第一步：必须断电！

```
MIPI DSI 不支持热插拔！必须在断电状态下操作，
否则可能烧毁板卡芯片或屏幕。
```

```bash
# 在板子上执行
poweroff
# 或拔掉 DC 电源
```

### 第二步：检查排线方向

野火 5.5 寸屏幕 FPC 排线是 **上翻下盖式** 连接器：

```
正确方向：触点（金手指）朝下（朝向 PCB），蓝色加强片朝上
错误方向：触点朝上 → 不导通
```

参照物：排线另一端连屏幕的那一侧，**触点面和屏幕同方向**。

### 第三步：检查是否插紧

FPC 连接器有一个 **翻盖**：
1. 先把翻盖**向上翻开**（解锁）
2. 排线**插到底**（插到蓝色加强片的边缘对齐连接器边缘）
3. 翻盖**向下压紧**（锁住，有咔哒感）

**常见错误：** 翻盖未锁紧，或排线未插到底。

### 第四步：确认接口位置

LubanCat-4 两个 DSI 接口**不在同一面**：

```
正面（元件面，有 CPU/散热片/40Pin）    背面
┌────────────────────────┐         ┌────────────────────────┐
│  [CPU]  [散热片]        │         │                        │
│                         │         │   dsi0 ← 30Pin FPC     │
│  [40Pin 排针]           │         │   ★ 屏幕插这里！       │
│                         │         │                        │
│   dsi1 ← 30Pin FPC     │         │                        │
└────────────────────────┘         └────────────────────────┘
```

| 接口 | 位置 | |
|------|------|------|
| **dsi0** | 板子**背面** | ← 屏幕插这里！ |
| **dsi1** | 板子**正面**（元件面） | |

### 第五步：检查排线完整性

- 排线有无明显折痕、断裂？
- 蓝色加强片是否还粘在排线上？
- 金手指触点有无氧化、脏污？

### 第六步：重新连接 + 上电

1. 确认方向正确（触点朝下）
2. 确认接口正确（dsi0）
3. 翻盖翻开 → 排线插到底 → 翻盖锁紧
4. 通电
5. 执行验证脚本

## 实际根因与修复

### 根因

**FPC 排线插在了 dsi1（板子正面 / 元件面），而非 dsi0（板子背面）。**

LubanCat-4 的两个 MIPI DSI 接口不在同一面：
- **dsi0** = 背面（30Pin FPC） — 屏幕应该插这里
- **dsi1** = 正面（元件面，30Pin FPC）

端口名虽然都是 DSI，但设备树中：
- dsi0 → VP2 → `card0-DSI-1`
- dsi1 → VP3 → `card0-DSI-2`

我们配置的 overlay 是 `dsi0-vp2`，只驱动了 dsi0，dsi1 没有对应的 overlay。因此插 dsi1 时 DRM 虽然能识别面板（status=connected），但面板没有正确的初始化序列，不会有显示。

### 修复

**断电 → 把排线从正面 dsi1 拔下 → 插到背面 dsi0 → 上电。**

### 为什么 DRM 显示 connected？

即使插在 dsi1，dmesg 中有 `panel-simple-dsi fde20000.dsi.0` 的 probe 日志，这是因为内核设备树中 DSI 两个端口都定义了 panel 节点。但 dsi1 没有 overlay 配置，**面板驱动加载了但初始化参数不完整**，所以 status=connected 但无显示。

### 经验教训

1. DSI0/DSI1 名称很像，容易搞混。记住：**背面 = dsi0**。
2. DRM `status=connected` ≠ 屏幕会亮。它只代表 HPD（热插拔检测）或 panel 探测成功，不代表面板初始化序列正确。
3. MIPI DSI 与 HDMI 不同 — HDMI 插任何口都能显示，DSI 必须 overlay 与端口匹配。
