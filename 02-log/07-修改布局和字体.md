> 日期：2026-07-23

## 目标

原 CSS 为 800×480 横屏设计，需等比缩放到 1920×1080 横屏。

## 缩放比例

| 维度 | 原始 | 目标 | 比例 |
|------|------|------|------|
| 宽度 | 800px | 1920px | **2.40x** |
| 高度 | 480px | 1080px | **2.25x** |

统一取 **2.3x**，向上取整。

## 运行配置

```bash
# 屏幕旋转
DISPLAY=:0 xrandr --output DSI-1 --rotate right

# Chromium (无缩放，1:1 像素)
DISPLAY=:0 chromium --kiosk --no-first-run --noerrdialogs \
    --window-size=1920,1080 http://localhost:8080 &
```

## 触摸校准

屏幕通过 `xrandr --rotate right` 旋转后，触摸坐标不会自动跟随，导致**点击位置和显示位置不一致**。

### 触摸设备

```
Goodix Capacitive TouchScreen (id=8, /dev/input/event2)
```

### 修复

对触摸设备应用 rotate right 坐标变换矩阵：

```bash
DISPLAY=:0 xinput set-prop 8 'Coordinate Transformation Matrix' 0 1 0 -1 0 1 0 0 1
```

**矩阵含义（顺时针 90° = rotate right）：**

| 原始 | → 变换 |
|------|--------|
| touch_x | → 屏幕 y |
| touch_y | → 屏幕 (1080 - x) |

即：`screen_x = touch_y`, `screen_y = 1080 - touch_x`

### 持久化

重启后触摸矩阵会重置。需要在 Chromium 启动前应用：

```bash
# /usr/local/bin/start-kiosk.sh
DISPLAY=:0 xinput set-prop 8 'Coordinate Transformation Matrix' 0 1 0 -1 0 1 0 0 1
xrandr --output DSI-1 --rotate right
chromium --kiosk --window-size=1920,1080 http://localhost:8080 &
```

## 后续如需微调

- 整体偏大/偏小 → 调整 body `font-size`（34px），其余使用 `rem` 相对单位
- 某个组件不对 → 单独调该组件的 px 值
- 触摸目标不够大 → 最小 48px 在 401 DPI 上约 3mm，可能需要加大到 60px+
