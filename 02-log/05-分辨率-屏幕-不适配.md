# 05 — 分辨率与屏幕不适配：诊断与最终修复

> 日期：2026-07-23
> 硬件：LubanCat-4 V1 + 野火 5.5 寸 MIPI DSI 1080×1920

---

## 问题现象

屏幕上 UI 大小不对——原工程为 800×480 横屏设计，屏幕实际 1080×1920 竖屏，完全不匹配。

---

## 尝试过程

### 尝试 1：`--force-device-scale-factor=2` + `width=device-width` + `100vw/100vh`

**做法：**
- Chromium 加 `--force-device-scale-factor=2`
- viewport 改 `width=device-width`
- CSS body 改 `100vw × 100vh`

**结果：** ❌ 内容溢出屏幕，超过屏幕大小。

**原因：** scale factor 和 device-width 和 vw/vh 三者相互作用，CSS 像素计算混乱，导致内容溢出。

### 尝试 2：`--force-device-scale-factor=2` + `width=800` + `100vw/100vh`

**结果：** ❌ 界面只显示了一小部分，屏幕大部分空白。

**原因：** viewport `width=800` 锁定了 800px，`100vw` = 800px，但 2x 缩放下屏幕 CSS 视口是 960px，200px 间隙白白浪费。

---

## 最终修复（可行方案）

**思路：屏幕是固定的 1920×1080，那就所有参数都硬编码为 1920×1080，去掉所有缩放。**

### 修改内容

**1. `static/index.html` — viewport 固定 1920：**

```html
<!-- 改前 -->
<meta name="viewport" content="width=800, initial-scale=1.0, user-scalable=no">

<!-- 改后 -->
<meta name="viewport" content="width=1920, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
```

**2. `static/style.css` — body 固定 1920×1080：**

```css
/* 改前 */
html, body { width: 800px; height: 480px; ... }

/* 改后 */
html, body { width: 1920px; height: 1080px; ... }
```

**3. 屏幕旋转为横屏：**

```bash
DISPLAY=:0 xrandr --output DSI-1 --rotate right
# 旋转后: 1080×1920 竖屏 → 1920×1080 横屏
```

**4. Chromium 启动参数（去掉 scale factor）：**

```bash
DISPLAY=:0 chromium --kiosk --no-first-run --noerrdialogs \
    --window-size=1920,1080 \
    http://localhost:8080 &
```

> ⚠️ 不加 `--force-device-scale-factor`，保持原始 1:1 像素映射。

---

## 当前工作配置

| 参数 | 值 |
|------|-----|
| 屏幕方向 | 横屏（`xrandr --rotate right`） |
| 分辨率 | 1920×1080 |
| viewport | `width=1920` |
| CSS body | `1920px × 1080px` |
| Chromium 缩放 | 无（1:1） |
| CSS 像素 : 物理像素 | 1:1 |

---

## 踩坑总结

1. **100vw/100vh 在固定尺寸屏幕上不好用** — 屏幕不会变，用 vw/vh 反而受 viewport 和 scale factor 干扰
2. **`--force-device-scale-factor` 引入额外复杂度** — 改变了 CSS 像素和物理像素的映射关系，和 viewport 宽度相互作用
3. **简单粗暴最有效** — 既然屏幕 1920×1080 固定不变，就把所有参数硬编码为 1920×1080，去掉缩放，1:1 像素映射，没有任何计算误差
4. **竖屏→横屏旋转是必要的** — 原工程 UI 是横屏布局，物理 1080×1920 竖屏需要 `--rotate right` 变成 1920×1080 横屏才匹配
