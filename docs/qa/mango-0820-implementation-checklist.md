# Mango 0820 原型实施与验收清单

## 约束

- 设备端、移动端与管理后台继续使用当前 Omega/shadcn 技术基座。
- 不改任何硬件服务、驱动或设备接口。
- GPS 为可选信息；未授权、超时、不可用或获取失败时保持空值，不得阻断任务领取与采集。
- 原型未提供的硬件数据使用明确的“待接入/无信号”状态，页面和软件流程仍可验收。
