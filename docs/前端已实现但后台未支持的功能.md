# 前端已实现但后台未支持的功能

## 说明

本文依据当前 `server.js` 路由和 React 前端实现进行核对。

- “完全缺失”表示后台没有对应业务接口。
- “部分支持”表示后台已有相近基础能力，但不能提供前端页面展示的完整数据或操作。
- 主题、语言、导航、沉浸模式和触屏键盘属于纯前端能力，不需要后台接口，因此不列为后台缺口。

## 功能缺口

| 状态 | 功能 | 前端具体位置 | 前端已经完成 | 后台缺少 |
|---|---|---|---|---|
| 完全缺失 | 任务平台与任务领取 | `数据 → 实时数据 → 领取任务` | 设备、场景、任务范围、项目、子任务选择；任务预览；确认领取按钮 | 项目列表、任务列表、任务详情、SOP、领取任务、领取结果和任务持久化接口 |
| 完全缺失 | 任务上下文保存 | `数据 → 任务领取 → 任务采集` | 任务采集页、当前任务信息、计划次数和已采集数量展示位置 | 当前任务查询、任务与录制记录关联、计划次数、完成进度和任务恢复接口 |
| 完全缺失 | 夹爪角度数据 | `数据 → 实时数据 → 夹爪角度` | 左右夹爪独立图表、角度范围和等待状态 | 左右夹爪实时角度、采样时间、在线状态和数据流接口 |
| 部分支持 | 多路独立相机画面 | `数据 → 相机`；`数据 → 开始采集` | FPV、左右手视频位和 FPV_L/FPV_R 双路采集布局 | 后台目前只有单路 `/api/camera/preview`；缺少独立左右路地址、每路连接状态和多路预览控制 |
| 完全缺失 | 云端信息上报 | `数据 → 开始采集 → 信息上报` | 固定操作位置、按钮和待接入反馈 | 上报目标、任务元数据、文件选择、上传、进度、重试和结果查询接口 |
| 完全缺失 | 设备商城 | `主页 → 设备与套件 → 查看全部` | HSuit/iSuit 展示、产品说明、标签和展示位 | 商品列表、详情、价格、库存、下单和订单状态接口 |
| 完全缺失 | 精选内容与内容播放 | `主页 → 精选内容` | 内容首页、采集指南列表、主内容和播放按钮 | 内容列表、详情、媒体地址、播放记录和推荐任务接口 |

| 完全缺失 | 二维码识别与设备绑定 | `我的 → 设备管理 → 添加设备 → 扫描二维码` | 设备类型选择、扫码页面、手动确认和绑定结果展示位置 | 摄像头二维码识别、二维码解析、设备校验、绑定和绑定结果接口 |
| 部分支持 | 独立传感器通道状态 | `我的 → 设备管理 → 设备信息` | 左右手相机、左右手压力等独立状态卡片 | 现有状态只能覆盖部分相机和手套连接信息；缺少每个传感器通道的独立在线状态和详细数据 |
| 完全缺失 | 设备软件包更新 | `我的 → 设备管理 → 大包下载` | 当前版本区域、检查更新、下载流程占位 | 当前版本查询、更新检查、包下载、校验、安装、进度和回滚接口 |
| 完全缺失 | 云端账户体系 | `我的 → 账户详情`；顶部账户条的“退出登录” | 本地账户状态、账户详情页、登录、注册和退出入口 | 登录、注册、退出、会话、用户资料、权限和云端同步接口 |
| 完全缺失 | 论坛 | `我的 → 系统 → 论坛` | 菜单位置和禁用状态 | 论坛地址、单点登录、内容或跳转配置接口 |
| 完全缺失 | 服务与支持 | `我的 → 系统 → 服务与支持` | 菜单位置和禁用状态 | 帮助内容、故障反馈、日志提交、工单和联系方式接口 |

## 已有后台支持、不要重复开发

以下功能已经有真实后台接口，不属于缺口：

- 设备、电量、存储、Wi-Fi、蓝牙和手套状态。
- 摄像头单路预览及预览启停。
- 录制启停和录制状态。
- 本地记录列表、删除、预览生成、IMU 解码和外接存储传输。
- Wi-Fi 扫描、连接和断开。
- 蓝牙扫描、连接和断开。
- 校准服务启动、停止、重启及左右手校准交接。
- 录制后自动处理设置读取和保存。

## 建议对接顺序

1. 任务平台、任务与录制关联、云端信息上报。
2. 硬件存在时接入多路相机、夹爪和独立传感器状态。
3. 多设备管理、二维码绑定和软件包更新。
4. 云端账户。
5. 商城、精选内容、论坛和服务支持。
