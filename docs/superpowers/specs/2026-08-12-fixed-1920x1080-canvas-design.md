# Device UI 固定 1920×1080 画布设计

## 目标

Device UI 始终按横屏 `1920×1080` 设计坐标系渲染。RK3588 逻辑桌面为 `1920×1080` 时 1:1 显示；本地浏览器可用区域较小时，整张画布等比缩小后居中显示。

## 渲染规则

- 内层 UI 画布固定宽 `1920px`、高 `1080px`。
- 缩放比例为 `min(viewportWidth / 1920, viewportHeight / 1080)`。
- 只缩放完整画布，不改变内部排版、字号、间距或断点。
- 画布在视口中水平、垂直居中，多余区域使用黑色背景。
- 禁止页面滚动和裁切，始终完整显示 16:9 画面。
- 窗口变化时立即重新计算缩放比例。

## 实现边界

新增一个只负责尺寸和缩放的视口容器，现有 `DeviceShell` 继续负责业务页面与导航，不改变业务逻辑。

## 验收

- `1920×1080` 视口下画布尺寸和缩放比为 `1920×1080 @ 1`。
- 小视口下页面完整可见，比例保持 16:9，无滚动条。
- 运行现有前端测试和生产构建，确认页面功能没有回归。
