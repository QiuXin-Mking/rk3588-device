# Fixed 1920×1080 Canvas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render the complete device UI on a fixed 1920×1080 canvas and scale the whole canvas down to fit smaller browser viewports.

**Architecture:** Add a focused `FixedCanvas` component around the existing application. It owns only viewport measurement and CSS scale; `App` and `DeviceShell` keep their existing business and layout responsibilities.

**Tech Stack:** React 19, TypeScript, CSS, Vitest, React Testing Library.

## Global Constraints

- The design canvas is exactly 1920px wide and 1080px high.
- Scale is `min(viewportWidth / 1920, viewportHeight / 1080)`.
- Never responsively reflow, crop, or scroll the design canvas.
- Center the scaled canvas and use black for unused viewport space.
